Personal backups for Google Drive

BTSRV Backup Service stores and restores the operator’s personal server backups using Google Drive.

How it works

The server creates compressed archives, copies them to a private Drive folder, and checks their integrity. The operator can download a verified archive to recover the server after data loss.

Google Drive permission

The operator authorizes access through Google. The service requests the per-file drive.file permission to create, list, verify, download and retire files managed by the application.
