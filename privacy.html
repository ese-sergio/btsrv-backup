Overview Privacy Terms

Privacy policy

BTSRV Backup Service uses Google Drive for the operator’s private backup and recovery tasks.

Data and purpose

Archives include world data, player profiles and progress, and the configuration and software needed for recovery. The service uses Drive file identifiers, sizes, checksums, sharing permissions and storage quota to manage and verify backups. OAuth credentials are stored separately on the server. Archives are compressed without an additional password.

Where information goes

Archives are stored locally and in the operator’s private Google Drive folder. Operational notifications go to the operator via Telegram and may contain archive names, timestamps, counts, sizes, available space and a private folder link. The link does not grant access to the folder.

Retention and deletion

Snapshots are scheduled twice daily. The local rotation keeps 28 versions. Pending uploads and restore-test copies may persist separately. Remote versions older than 30 days are moved to Drive trash only after a recent valid backup is confirmed. Trash follows Google Drive’s deletion policy. The operator can remove copies directly from Drive and empty its trash for permanent deletion.

Google API data

Google API data is used for backup, integrity checking, recovery and related status reports. The service does not sell this data or use it for advertising. These use limits reflect the Google API Services User Data Policy, including Limited Use.

Revoke access

Open Google Account connections, select the application, and remove its access. This stops future authorized Drive operations. Existing archives remain until deleted.
